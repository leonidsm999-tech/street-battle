# Bazar Battle (Дворовая Стрелка) — Fabric 1.21.1

Мод для Minecraft **1.21.1 (Fabric)**, в котором вместо обычной боёвки ты «перебазариваешь» мобов в микрофон по понятиям под легендарный саундтрек (**«Как у Коляна»**), вплетая слова из суфлера на экране, а нейросеть **Gemini** выступает беспристрастным Смотрящим.

## Как собрать `.jar` через GitHub (без установки Gradle на ПК)

1. Создайте новый репозиторий на GitHub (можно приватный или публичный).
2. Распакуйте этот архив и загрузите все файлы в корень репозитория (через веб-интерфейс GitHub `Add file -> Upload files` или через `git push`).
3. Перейдите во вкладку **Actions** вашего репозитория на GitHub — сборка запустится автоматически!
   * GitHub Actions сам установит `ffmpeg`, сконвертирует `raw_audio/battle_theme.mp3` в `battle_theme.ogg` и соберёт готовый мод.
4. Когда рядом с воркфлоу загорится зелёная галочка, откройте его и внизу в разделе **Artifacts** скачайте `bazar-battle-1.21.1-jar`.

## Установка и настройка

1. Положите скачанный `.jar` (и **Fabric API** для 1.21.1) в папку `.minecraft/mods/`.
2. Запустите игру один раз — создастся файл конфигурации `.minecraft/config/bazar_mod.properties`.
3. Откройте `config/bazar_mod.properties` и вставьте свой бесплатный ключ из [Google AI Studio](https://aistudio.google.com/):
   ```properties
   api_key=ВАШ_КЛЮЧ_GEMINI
   model=gemini-2.5-flash
   ```
   *(Если Gemini API недоступен напрямую из вашего региона, укажите `proxy_host=127.0.0.1` и `proxy_port=порт_вашего_прокси`. Для проверки без ключа можно поставить `mock_mode=true`.)*
4. В игре выполните `/bazar reload`, чтобы применить конфиг без перезапуска!

## Управление в игре

* **Удар по любому мобу** — запускает «Стрелку» на 15 секунд: играет фоновая тема, сверху появляется предъява моба и 3–6 слов-триггеров, которые нужно вплести в свой ответ в микрофон.
* **`/bazar test`** — мгновенно вызывает ближнего моба (или спавнит «Дворового Зомби») на стрелку.
* **Клавиша `G`** — если рядом с вами стрелку начал друг, нажмите `G`, чтобы вписаться за него и разделить слова суфлера.
